# Employee Management System

A full-stack Employee Management System built with **FastAPI** (Python + PostgreSQL) on the backend and **React + TypeScript + Vite** on the frontend.

---

## 📋 System Prerequisites

Before running the project, make sure you have the following installed on your machine:

1. **Python 3.10+**: [Download Python](https://www.python.org/downloads/)
2. **Node.js (v18+) & npm**: [Download Node.js](https://nodejs.org/)
3. **PostgreSQL**: Running locally (default configured for port `5433`).

---

## 🗄️ Step 1: Database Setup (PostgreSQL)

1. Make sure your PostgreSQL server is running.
2. Create a database named `employee_management`:
   - Using **pgAdmin** or **psql**:
     ```sql
     CREATE DATABASE employee_management;
     ```
3. Check database credentials in `backend/app/database.py`:
   ```python
   DATABASE_URL = URL.create(
       drivername="postgresql+psycopg",
       username="postgres",
       password="YOUR_POSTGRES_PASSWORD", # Currently configured: Hema@473
       host="localhost",
       port=5433,                         # Update port if your Postgres runs on 5432
       database="employee_management"
   )
   ```
   > **Note:** Tables are automatically generated by SQLAlchemy when the backend starts up!

---

## 🚀 Step 2: Backend Setup & Run (FastAPI)

Open your first terminal (PowerShell or Command Prompt) and run:

### 1. Navigate to the backend directory:
```powershell
cd backend
```

### 2. Activate the virtual environment:
- **On Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
  *(If you get a script execution policy error, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` first)*

- **On Windows (CMD):**
  ```cmd
  venv\Scripts\activate.bat
  ```

- *(Optional - If setting up a fresh environment without existing venv)*:
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  pip install -r requirements.txt
  ```

### 3. Start the FastAPI server:
```powershell
uvicorn app.main:app --reload --port 8000
```

### 4. Verify Backend:
- **API Home:** [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
- **Interactive Swagger Documentation:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

---

## 💻 Step 3: Frontend Setup & Run (React + Vite)

Open a **second terminal** and run:

### 1. Navigate to the frontend directory:
```powershell
cd frontend
```

### 2. Install dependencies (if not already installed):
```powershell
npm install
```

### 3. Start the Vite development server:
```powershell
npm run dev
```

### 4. Open the Web Application:
- Open your browser and navigate to: **[http://localhost:5173/](http://localhost:5173/)**

---

## 🔑 Step 4: Login & Using the Application

1. Open the frontend at `http://localhost:5173`.
2. Sign in with any employee email already registered in your PostgreSQL database (e.g. `h@gmail.com`).
3. To add a new employee or seed initial data:
   - Visit the Swagger UI at [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
   - Open `POST /employees` and click **Try it out**
   - Provide the employee details (name, email, department, role) and click **Execute**
   - Use that new email to sign in on the frontend.

## 🛠️ Troubleshooting

| Issue | Cause & Solution |
| :--- | :--- |
| **Database Connection Error (`connection to server at "localhost", port 5433 failed`)** | Ensure PostgreSQL is active on port 5433 (or change port to 5432 in `backend/app/database.py`). Verify database name `employee_management` exists. |
| **PowerShell script execution policy error (`running scripts is disabled`)** | Run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in PowerShell, then activate venv again. |
| **CORS error in browser console** | Ensure backend is running at `http://127.0.0.1:8000` or `http://localhost:8000`. CORS is enabled for port `5173` by default in `main.py`. |
| **Employee not found on Login** | Make sure you have created the employee record in PostgreSQL via Swagger UI (`http://127.0.0.1:8000/docs`) before logging in. |
